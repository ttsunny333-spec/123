# Runa — универсальная платформа знаний и систем

Личное приложение в стиле Notion: заметки с блочным редактором, базы данных, свойства, связи.
Пользователь говорит по-русски, пишет голосом, раздражается на лишние вопросы и пустые обещания. **Отвечай по-русски, коротко, делай, а не спрашивай.** Токены у пользователя ограничены: не перечитывай файлы без нужды, не пиши длинных отчётов.

## Как выкладывать
- Репозиторий: `ttsunny333-spec/123`, ветка `main`. Проект лежит **в корне репозитория**, Root Directory в Vercel пустой.
- Каждый push в `main` собирается Vercel сам: https://runa-ludvig-one-bitcoin.vercel.app (проект `runa`, id `prj_5zYVqmG4zOlwebR91CWIA59Bxr6Z`, команда `ludvig-one-bitcoin`).
- Перед push: `npm test` (27 тестов ядра) и `npx tsc --noEmit`. Сайт в браузере проверить нельзя, поэтому сборка и тесты — единственная проверка. Не ломай сборку: `noUnusedLocals` включён.

## Стек
React 18 + Vite + TypeScript, zustand, TipTap 2 (редактор), Supabase (база, вход, хранилище), lucide-react, KaTeX и Mermaid (подгружаются по требованию). Без react-router: страницы переключаются состоянием в `App.tsx`, открыть заметку из любого места — `openNote(id)` из `ui/nav.ts`.

## Инфраструктура
- Supabase: проект `mxjgeixnrjamidztqzvx` (eu-central-1). Переменные `VITE_SUPABASE_URL`, `VITE_SUPABASE_KEY` заданы в Vercel.
- Миграции: `supabase/migrations/0001…0007`, **все применены**. Новая миграция = новый файл + применить к проекту.
- Хранилище: приватный бакет `media`, лимит 50 МБ, у каждого пользователя своя папка `<user_id>/` (RLS).
- Edge-функция `link-preview` (превью ссылок для блока «Закладка», `verify_jwt: true`, код в `supabase/functions/link-preview/`, чистая логика в `parse.ts` с тестами).

## Устройство кода
- `src/core/` — модель без UI и без сети: `types.ts`, `ops.ts` (операции insert/update/remove с откатом), `history.ts` (отмена/повтор), `commands.ts` (создание/перемещение/удаление), `properties.ts`, `views.ts`, `schema.ts` (пользовательские типы и связи), `queries.ts`, `mentions.ts`, `graph.ts`, `canvas.ts`. Все изменения идут через `useApp.getState().commit(label, ops, {mergeKey?})`.
- `src/data/` — `repository.ts` (синхронизация со Supabase), `supabase.ts`, `media.ts` (загрузка файлов, временные ссылки), `embeds.ts` (ссылки YouTube/Figma и т.д.), `markdown.ts` (экспорт в .md и ZIP).
- `src/state/store.ts` — zustand: данные, commit/undo/redo, синхронизация, уведомления.
- `src/ui/` — интерфейс. `Sidebar.tsx`, `Home.tsx`, `NotePage.tsx`, `NoteHeader.tsx` (обложка, значок, комментарии), `props/` (свойства), `theme.ts` + `themes.css` (5 тем), `Exchange.tsx` (экспорт/импорт).
- `src/ui/editor/` — редактор. **Блоки описываются в реестре** `registry.ts` (`registerBlock`), меню «/» строится из него. Файлы блоков: `nodes.tsx` (выноска, раскрывающийся, колонки, вкладки, страницы, оглавление, код), `media.tsx` (картинка, галерея, видео, аудио, файл, PDF, закладка, встраивание), `math.tsx` (формула, Mermaid), `wave4.tsx` (прогресс, статус, кнопка, шаблоны графика/блок-схемы/майнд-карты), `database.tsx` (база данных). Новый блок = Node TipTap + `registerBlock` + подключение в `Editor.tsx`.
- Модель данных: всё — объекты (`Obj`) в «системе» (`SystemRec`). Заметка = объект типа `page`, вложенность через `parentId`. Свойства — определения `PropertyDef` на уровне системы со значениями в `obj.props[propId]`, область действия `appliesTo` (типы). **База данных** = страница-хозяин + свой тип записей + табличный вид (`views`); строки — дочерние объекты этого типа; колонки привязаны к типу, поэтому не засоряют другие заметки. Значок/обложка/комментарии заметки лежат в `props` под ключами `builtin.icon|cover|comments`.
- Единственное «пространство» заметок создаётся автоматически при первом входе (`ui/notes.ts`).

## Что готово
Вход (почта/пароль, Google); заметки с деревом в левой панели, переименование, удаление с отменой; значок, обложка, комментарии; ~45 блоков редактора по каталогу (текст, списки, чек-лист, раскрывающиеся, выноска, код, таблица, колонки, вкладки, страницы и ссылки, @-упоминания, оглавление, крошки, якорь, форматирование и цвета); медиа (загрузка и вставка из буфера); формулы и диаграммы; прогресс/статус/кнопка; свойства заметок; блок «База данных» (таблица, свои колонки, сортировка); главная («Недавние» и «Все заметки»); мобильный режим (панель выезжает, кнопка ☰); 5 тем; экспорт .zip и импорт .md; «Упоминается в» внизу заметки.

## Что НЕ сделано (по порядку, который выбрал пользователь)
1. **Канбан** для баз данных (в ядре уже есть `kanbanColumns`/`moveCard`, UI нет).
2. Переключение видов базы (таблица/канбан), **фильтры, группировка**, поиск по базе.
3. **Связи**: свойство-связь с выбором объекта, типизированные связи, обратные ссылки как поле. Ядро умеет, UI нет.
4. **Граф связей** и **холст** (в ядре есть `graph.ts`, `canvas.ts`; интерфейс удалён при переделке).
5. Блоки «Связанный вид базы», «Синхронизированный блок», «Таблица с формулами» (пока пункты «скоро» в меню «/»).
6. Работа без интернета (локальная копия), ежедневные заметки, шаблоны, календарь/гант, поиск по всему (Ctrl+K), избранное.
7. Уровни 3–5 замысла: **Modules** (симуляция, прототипы, игровые механики, тесты, обучение), **Builder** (конструктор рабочих сред из сущностей/механизмов/модулей), **Workspace** (Game/App/Course Studio), плагины. Несколько пространств есть в данных, в интерфейсе нет.

## Известные ограничения
- Файлы из хранилища при удалении блока не удаляются (чтобы работала отмена). Нужна будущая «уборка».
- Старый интерфейс (с холстом, графом, Notion-подобной панелью) лежит в архиве `runa-old-ui-backup.zip` у пользователя — оттуда можно брать идеи, но код устарел.
- Импорт .md кладёт разметку как текст, не превращая её в блоки.
