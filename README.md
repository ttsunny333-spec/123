# Runa

Рабочая среда для построения сложных систем: курсов, игр, архитектуры продуктов, баз знаний.

## Этап 1 — ядро (текущая версия)

- Системы: создание, переименование, архив, восстановление, удаление.
- Универсальные объекты (`area`, `folder`, `page`, `task`) с произвольной вложенностью.
- Дерево структуры: создание, переименование (двойной клик или F2), перетаскивание до/после/внутрь, контекстное меню, смена типа, архив (Del).
- Страница объекта: название, тип, заметки, вложенные объекты, хлебные крошки.
- Единая шина операций: undo/redo (Ctrl+Z / Ctrl+Shift+Z), склейка набора текста в один шаг, атомарные транзакции, защита от циклов в иерархии.
- Автосохранение в Supabase с повтором при обрыве связи и индикатором состояния.
- Поиск и команды: Ctrl+K. Скрыть структуру: Ctrl+\.

## Устройство

```
src/core      доменная модель, операции и их инверсии, команды, запросы, история (без React, покрыто тестами)
src/data      Repository-интерфейс и реализация для Supabase
src/state     стор: применение транзакций, undo/redo, синхронизация, загрузка
src/ui        оболочка, дерево, страницы, палитра команд
supabase/     миграции схемы с RLS
```

Все изменения проходят через `commit(label, ops)`: операции валидируются, применяются атомарно,
попадают в историю и помечают записи для синхронизации. Представления никогда не пишут в базу напрямую.

## Запуск локально

```bash
npm install
cp .env.example .env.local   # вставьте URL и ключ проекта Supabase
npm run dev
npm test                     # тесты ядра
npm run typecheck
```

## Деплой

Vercel собирает проект командой `npm run build` (фреймворк Vite). В настройках проекта нужны
переменные `VITE_SUPABASE_URL` и `VITE_SUPABASE_KEY`.
